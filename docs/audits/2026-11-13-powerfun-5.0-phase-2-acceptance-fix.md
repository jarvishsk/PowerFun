## 1．对验收意见的逐条回应

### 2 阻断项一：短期总样本达标掩盖单项有效样本不足 — 接受，已修正

确认属实。`_calc_short_term()` 此前只按总样本 `n≥5` 给方向 verdict，未校验各指标自身有效样本。

**修正方式**（`src/deep_analyzer.py` `_calc_short_term()`）：

1. 新增 `hr_valid_n / pace_valid_n / eff_valid_n`（各指标非缺失计数，效率用 `df_eff_valid`）与 `curr_hr_valid / curr_pace_valid`（当前值非 NaN 且 >0），并随结构化结果返回 `hr_valid_samples / pace_valid_samples / eff_valid_samples`。
2. 新增 `_dir_verdict()` 辅助统一方向判定（心率/配速为「低优」，效率为「高优」，避免第一版泛化把效率方向写反）。
3. `n≥5` 时，每项须自身有效样本 ≥5 且当前值有效才给该项 verdict；不足项保留描述性中位数与差值，仅不给方向。
4. 存在不足项或当前值缺失时，`evidence_reason` 改为逐项计数说明：「总样本 n=X；心率有效 a、配速有效 b、效率有效 c；有效样本不足 5 或当前值缺失的指标仅作描述，不给方向判断」，不再统称「样本充足」。
5. HTML（`src/analysis_report.py`）与 Prompt（`_format_comparison()`）：verdict 为 None 的项渲染「样本有限（有效 n 次）」并附 `evidence_reason`，不输出 `None`、不把缺失当前值判为「持平」。

### 3 阻断项二：全量稳定但对单月敏感仍输出「稳定」 — 接受，已修正

确认属实。`elif not direction_metrics:` 分支此前直接输出「稳定」，未消费 stable 类指标的 `direction_stable`，构成敏感性盲区。

**修正方式**（`src/deep_analyzer.py` `_calc_long_term()`）：

1. stable 类指标同样消费 `direction_stable`：新增 `loo_unstable_stable`（全量在阈值内但逐月剔除方向不稳的指标列表），并随结构化结果返回。
2. 非空时 → `verdict='趋势待确认'`、`verdict_allowed=False`、`evidence_level='descriptive'`，理由标明敏感指标：「X 全量在阈值内但逐月剔除后方向不稳，稳定结论待确认」。
3. 仅当全量分类与逐月剔除分类均支持稳定时，才使用「各项指标变化在正常范围内，逐月剔除方向分类一致」理由。
4. 「全量有方向但全部敏感」「部分稳定方向指标支撑 verdict」两个既有分支的行为与测试未动。

### 4 随附文案修正：效率负向斜率 — 已修正

`_signal_reasons()` 效率负向分支已由泛化三元表达式改为显式 if/elif：负向输出「效率月降{abs(slope):.1f}」，正向保留「效率月升{slope:.1f}」，不再出现「效率月升-」。
