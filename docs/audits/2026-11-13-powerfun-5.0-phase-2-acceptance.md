## 2．阻断项一：短期总样本达标掩盖单项有效样本不足

### 2.1 位置与原因

`src/deep_analyzer.py` 的 `_calc_short_term()` 在第 1087—1097 行附近只判断：

```python
n_samples = len(df_same_temp)
if n_samples >= SHORT_TERM_DIRECTIONAL_MIN:
    hr_verdict = ... if hr_diff is not None else None
```

总活动数达到 5 次后，只要某项中位数和差值不是 `None`，就给该项方向 verdict；没有要求心率、配速、效率各自的有效样本数达到 5。

PRD 第 3 节要求“总活动数达标但某指标有效值不足时，该指标不得给方向结论”，第 10.1 节要求“只降级该指标”。当前实现只覆盖某指标全部缺失，没有覆盖部分缺失。

### 2.2 合成复现

五次历史活动中仅一次心率有效，其余心率缺失；配速全部有效。实际结果：

```text
短期总样本=5、心率有效样本=1：
verdict_allowed=True
verdict_hr='更累'
verdict_pace='更慢'
evidence_reason='样本充足（n=5），沿用现有阈值…'
```

一次心率观测不能支撑“心率更累”的短期方向判断，也不应被描述为该项样本充足。

### 2.3 最小修正要求

1. 分别计算并返回心率、配速、效率的有效样本数。
2. `n≥5` 时，每项仍须自身有效样本达到 5，且当前值有效，才允许该项 verdict；其他达标指标不受影响。
3. 不足项可以保留描述性中位数和差值，但必须带有效样本数，不得给方向 verdict。
4. `evidence_reason` 不得再把所有指标统称为“样本充足”；HTML／Prompt 不得输出 `None` 或把缺失当前值判为“持平”。
5. 增加测试：
   - 总样本 5、心率有效 1／4：心率无 verdict，配速正常；
   - 总样本 5、效率有效不足 5：效率无 verdict；
   - 当前心率为 NaN：心率无 verdict，不得为“持平”；
   - 对应 Prompt 不出现 `None`，HTML 对不足项显示“样本有限”。

## 3．阻断项二：全量稳定但对单月敏感时仍输出“稳定”

### 3.1 位置与原因

`_calc_long_term()` 先只用全量超阈值指标构造 `direction_metrics`：

```python
direction_metrics = [m for m in (...) if classes[m] != 'stable']
```

随后 `elif not direction_metrics:` 直接输出“稳定”，没有检查全量阈值内指标的 `direction_stable`。

这使“全量稳定”成为敏感性检查的盲区，并且固定理由“各项指标变化在正常范围内，逐月剔除方向分类一致”可能与结构化敏感性结果直接矛盾。

### 3.2 合成复现

同温区 4 个月、每月 3 次，心率月均值 `[150, 150, 150, 153]`：

- 全量心率斜率约 `+0.90 bpm/月`，在阈值内；
- 逐月剔除斜率范围 `0.0—1.5`，`direction_stable=False`；
- 实际仍返回：

```text
verdict='稳定'
verdict_allowed=True
evidence_reason='各项指标变化在正常范围内，逐月剔除方向分类一致'
```

复现脚本为 `.runtime/acceptance/phase2/verify_edges.py`，仅使用合成数据。

### 3.3 最小修正要求

1. 对全量阈值内指标同样消费 `direction_stable`。
2. 若全量“稳定”依赖的指标在逐月剔除后转为方向性变化，不得输出确定的“稳定”，应返回“趋势待确认”并标明敏感指标。
3. 只有全量分类及逐月剔除分类均支持稳定时，才可使用“各项指标逐月剔除方向分类一致”的理由。
4. 增加上述合成场景测试，断言 `verdict='趋势待确认'`、`verdict_allowed=False`，且不得出现“逐月剔除方向分类一致”。
5. 保留现有“全量有方向但全部敏感”和“部分稳定方向指标支撑 verdict”的行为与测试。

## 4．随附文案修正：效率负向斜率方向写反

`_signal_reasons()` 对效率负向斜率使用：

```python
f'效率月升{slope:.1f}'
```

负向时会生成“效率月升-1.5”，既重复负号又把“下降”写成“上升”。应恢复为负向“效率月降 {abs(slope)}”，正向保留“效率月升”。

该项不单独阻断，但应与阻断项二一并修正，并增加负向效率理由测试，避免报告内部方向矛盾。
