## 1．背景与问题

第一批已经修正课型和 Pa:Hr，但统计输出仍把“有数字”近似当成“有能力变化证据”：

1. 短期基线只有 3—4 次时，也直接输出“更快、更累、更经济”等方向判断。
2. 长期跨温区回归仍输出“进步／退步”，温度的季节混杂可能被解释为能力变化。
3. 月度回归对单月离群值的敏感性没有呈现，少量月份可能主导结论。
4. 去年同期只要累计 3 次，就按逐次活动做日期回归；这 3 次可能集中在同一月份，不能支持“每月变化”。
5. 历史百分位只要求 5 个样本，排名容易给人过度精确的错觉。

本批的目标不是减少数据展示，而是把输出拆成两层：

- **表现描述**：中位数、差值、月度中位数、回归斜率等事实可以保留；
- **能力判断**：只有样本量、温度可比性和单月敏感性达到要求时，才允许输出方向性 verdict。

## 2．已确认的原则与边界

### 2.1 必须实施

- 短期每组 `n≥5` 才给谨慎方向；`n=3—4` 保留中位数和差值但不给 verdict；`n<3` 数据不足。
- 长期保留月度中位数及回归数值作描述；跨温池不直接输出能力“进步／退步”。
- 长期增加逐月剔除敏感性检查。
- 保留至少 3 个有效月份、普通课型每月≥2、LSD 每月≥1的既有护栏。
- `baseline_scope` 继续使用 `same_temp/all_temp/no_temp`。
- LSD 的 `no_temp` 参照池不变，但不能把跨温结果包装成已排除温度影响的能力证据。
- 同比每个指标至少 3 个有效样本才可展示中位数；同比斜率至少 3 个有效月份。
- 历史百分位有效样本门槛由 `n≥5` 提高到 `n≥10`。

### 2.2 明确不做

- 不改变第一批人工课型、Pa:Hr 选段和缓存哈希协议。
- 不改变短期 60 天、长期及同比 180 天窗口，不改变基线选择顺序。
- 不建立个人温度修正系数，不删除跨温数据，不为了凑同温样本缩小数据池。
- 不引入加权回归、置信区间、显著性检验或新的统计模型。
- 不通过 IQR 或单次状态异常删除整次活动。
- 不重做负荷、强度、技术效率、间歇组、夏季同比或分圈分析。
- 当前分圈每公里 `n≥10` 的实现保留，不重复改造。
- 不修改六小节及 `<<<BRIEF>>>...<<<END>>>` 协议，不提升 Prompt 版本。
- 不修改正式 `data/`、`reports/`、`cache/` 内容，不 commit／push。

## 3．统一结构化证据语义

本批应在 Python 确定性内核中给出证据等级，HTML 和 `_format_comparison()` 只消费结果，不得各自重新判断样本门槛。

建议字段名如下；如实现需调整，必须在交付中说明并保持一致：

```text
evidence_level = directional | descriptive | insufficient
verdict_allowed = true | false
evidence_reason = 人类可读的简要原因
```

含义：

- `directional`：允许输出方向性能力／状态判断；
- `descriptive`：只展示数值和相对位置，不输出能力 verdict；
- `insufficient`：对应结果不计算或不展示，说明样本不足。

“未给 verdict”不等于“持平”。样本不足或证据不足时，方向字段应为 `None` 或使用明确的“证据不足／趋势待确认”，不能默认填入“稳定／持平”。

每个指标独立处理缺失值。总活动数达标但某指标有效值不足时，该指标不得给方向结论。

## 4．F1：短期状态增加样本证据门槛

涉及 `_calc_short_term()`、对应 HTML 和 `_format_comparison()`。

### 4.1 样本规则

基线选择完成后，按实际选中的同类型样本数 `n`：

| 样本量 | 中位数与差值 | 方向 verdict |
| --- | --- | --- |
| `n<3` | 不形成短期基线结论 | 数据不足 |
| `3≤n<5` | 保留并展示 | 禁止；标为“样本有限，仅作描述” |
| `n≥5` | 保留并展示 | 允许沿用现有阈值，表述保持谨慎 |

现有阈值不变：

- 心率差 `<-3 / >+3 bpm`；
- 配速差 `<-5 / >+5 秒/km`；
- 效率差 `<-3 / >+3`。

本批不重新论证或调整这些阈值。

### 4.2 数据契约

- 继续返回当前值、基线中位数、`sample_size` 和 `baseline_scope`。
- 将已计算的差值显式返回：心率 bpm、配速秒/km、效率原单位；无效值为 `None`。
- `3≤n<5` 时，`verdict_hr/verdict_pace/verdict_efficiency` 必须为 `None`，并返回描述级证据字段。
- `n≥5` 时，才按现有公式填写三个 verdict。
- 不把 `message` 用于 `n=3—4` 的正常描述场景；现模板以 `message` 隐藏整个短期区块，不能沿用这一方式吞掉中位数和差值。

### 4.3 展示与模型约束

- HTML 在 `n=3—4` 时仍显示当前值、中位数和差值，徽标用中性的“样本有限”，不得显示“更快／更慢／更轻松／更累／更经济／更费力”。
- `_format_comparison()` 必须把差值和“仅作描述”注入模型上下文，不能只写样本不足，也不能暗中填入方向 verdict。
- 模型可以陈述“本次比近 4 次中位心率高 2 bpm”，不得据此写成“近期状态下降／能力提升”。

## 5．F2：长期跨温趋势只作表现描述

涉及 `_calc_long_term()`、`_long_term_regression()`、HTML 和 `_format_comparison()`。

### 5.1 保留既有计算与护栏

- 月度中位数、真实月份间隔和未加权线性回归保持不变。
- 至少 3 个有效月份才回归。
- 普通课型每月至少 2 次才计入回归；LSD 每月至少 1 次。
- 同温区不足时回退跨温区的现有选择逻辑不变。
- LSD 继续使用 `no_temp` 全 LSD 同池，不缩小参照池。
- 180 天窗口内不恢复 30 次样本截断。

`months_available` 应明确表示实际进入回归的有效月份数；如需同时保留过滤前月份数，另设 `months_with_data`，不得混用。

### 5.2 温度与能力 verdict 分离

| `baseline_scope` | 月度中位数与斜率 | 能力“进步／退步／稳定／分化” |
| --- | --- | --- |
| `same_temp` | 保留 | 通过敏感性检查后允许 |
| `all_temp` | 保留，仅作描述 | 禁止 |
| `no_temp` | 保留，仅作描述 | 禁止 |

跨温结果必须明确：

```text
verdict = 能力证据不足
verdict_allowed = false
evidence_level = descriptive
```

原因应说明“跨温区样本未排除温度影响，仅描述该参照池中的表现变化”，而不是写成“数据不足”。这里有数据，只是没有足够可比的能力证据。

不得通过给“进步”加括号“跨温区基线”继续输出能力判断。模型不得把斜率符号自行翻译成能力进步或退步。

### 5.3 描述数据保留

回归结果除斜率外，返回实际进入回归的月度中位点，至少包含：

- 月份；
- 该月有效活动数；
- 心率中位数；
- 配速中位数；
- 由月度中位心率与配速计算的效率值。

这些字段用于回放、敏感性检查和模型事实上下文，不要求新增图表。

## 6．F3：逐月剔除敏感性

### 6.1 最简实现

对实际进入回归的月份执行 leave-one-month-out：

1. 每次剔除一个有效月份；
2. 用其余月份重新计算三项斜率；
3. 记录每项指标各次斜率范围，以及方向分类是否与全量结果一致；
4. 不删除原活动，不改变原始回归值。

至少返回：

```text
sensitivity = {
  <metric>: {
    leave_one_out_min: ...,
    leave_one_out_max: ...,
    direction_stable: true | false
  }
}
```

方向分类沿用当前阈值和夏季倍率：正向、负向、阈值内稳定。`direction_stable=true` 要求每次逐月剔除后的分类都与全量分类一致。

### 6.2 对 verdict 的作用

- `same_temp`：只有全量斜率超过方向阈值且逐月剔除后方向分类仍一致的指标，才可作为“进步／退步”的正负信号。
- 对单月敏感的指标不得强行纳入正负信号，应在 `reason` 或单独字段中说明“对单月敏感”。
- 若原本会给出方向结论，但所有方向指标均对单月敏感，则输出“趋势待确认”，不能退化为“稳定”。
- `all_temp/no_temp`：敏感性结果保留作描述，但无论是否稳定，都不得升级为能力 verdict。

本检查只是稳健性提示，不得称为统计显著性或因果证明。

## 7．F4：去年同期中位数与斜率分别设门槛

涉及 `_calc_yoy()` 及其 HTML／Prompt 格式化。

### 7.1 中位数

- 去年同期窗口和课型池保持不变。
- 心率、配速分别要求至少 3 个有效样本，才返回并展示对应中位数。
- 总样本数继续返回；不能用“总活动≥3”替代某指标自身的有效样本要求。
- 少于 3 个有效样本时，不显示该指标中位数，不给方向评价。

### 7.2 斜率

删除目前“累计 3 次活动即按日期逐点回归”的实现，改为与长期一致的月度中位数回归：

- 先按月计算中位数；
- 普通课型每月≥2、LSD 每月≥1；
- 至少 3 个有效月份才返回斜率；
- x 轴使用真实月份间隔，不按活动序号或固定 30 天逐次回归；
- 同一自然月内的 3 次活动可以支持中位数，但不能支持“每月斜率”。

不满足月份门槛时，`hr_slope_per_month` 和 `pace_slope_per_month` 字段应缺失或为 `None`，HTML 和 Prompt 均不得展示。

夏季同比 `_calc_summer_yoy()` 不在本批修改范围内。

## 8．F5：历史百分位使用有效样本 n≥10

涉及 `_calc_percentile()`。

- 在当前效率有效、历史效率清洗完成后，历史有效效率样本不足 10 个时返回 `None`。
- 门槛判断不能只看书 dataframe 行数，必须看实际参与排名的有效效率值数量。
- `n=9` 不出排名，`n=10` 才允许计算。
- 百分位公式、30 次上限、标签分档和基线池选择不变。
- 样本不足时 HTML／Prompt 不显示排名，不得显示“P0”或把缺失当作落后。

## 9．HTML、Prompt 与缓存一致性

### 9.1 两个出口必须使用同一证据语义

重点修改：

- `src/analysis_report.py` 的短期、长期、同比、百分位区块；
- `src/deep_analyzer.py` 的 `_format_comparison()` 与必要的教练说明。

不得出现 Python 已禁止 verdict，但 HTML 仍显示旧方向，或 Prompt 仍向模型提供“判定进步”的情况。

### 9.2 教练表达边界

- 描述级数据可以比较高低、快慢和数值变化，但必须带上参照范围与限制。
- 跨温长期趋势只能说“该跨温参照池内心率／配速月均数值如何变化”，不能说“跑者能力提高／下降”。
- 小样本短期比较不能外推为近期状态趋势。
- 单月敏感趋势不能作为训练调整的唯一依据。
- 不需要修改六小节标题、顺序或 BRIEF 协议。

### 9.3 缓存与版本

- 结构化 `analysis_data` 变化会自然改变第一批的 `analysis_hash`，旧点评应未命中并重新 prepare。
- 不通过提升 `LLM_PROMPT_VERSION` 强制失效；保持 12。
- `VERSION` 保持 4.1。

## 10．测试要求

新增测试建议集中在 `tests/test_statistical_evidence_gates.py`，并按需更新既有确定性场景。不得删除断言换取通过。

### 10.1 短期

1. `n=2`：数据不足，无 verdict。
2. `n=3`、`n=4`：当前值、中位数和差值存在，三个方向 verdict 均为 `None`；HTML 与 Prompt 不出现旧方向词。
3. `n=5`：现有阈值方向正确。
4. 总数达标但单指标有效值不足：只降级该指标。
5. `all_temp` 与 `no_temp` 的短期基线选择行为不变。

### 10.2 长期与敏感性

1. 普通课型每月 1 次不计入回归；每月 2 次可计入；有效月份不足 3 时不回归。
2. LSD 每月 1 次可计入，仍至少 3 个有效月份。
3. `months_available` 等于实际进入回归的月份数。
4. `all_temp`：斜率和月度中位点保留，但无“进步／退步／稳定／分化”能力 verdict。
5. `no_temp`：LSD 池不变，同样只作描述。
6. `same_temp` 且逐月剔除稳定：允许按现有规则给 verdict。
7. 构造单月主导样例：全量有方向，但剔除关键月份后方向改变；该指标不得支撑能力 verdict。
8. `same_temp/all_temp/no_temp` 的既有选择顺序不变。

### 10.3 同比

1. 每指标 2 个有效样本不中显，3 个可显示中位数。
2. 同一月 3 次活动：有中位数、无月斜率。
3. 普通课型 3 个月但每月仅 1 次：无月斜率。
4. 普通课型至少 3 个有效月份且每月≥2：有月斜率。
5. LSD 至少 3 个有效月份且每月≥1：有月斜率。
6. 间隔不等月份使用真实月份距离。

### 10.4 百分位

1. 9 个有效效率样本返回 `None`。
2. 10 个有效样本正常计算。
3. dataframe 行数≥10 但有效效率只有 9 个时仍返回 `None`。
4. 既有 P73 等充足样本场景公式不变。

### 10.5 全量回归

```bash
.venv/bin/python -m pytest tests/ -q
```

第一批 84 项测试应保留；因本批口径确实改变而需要更新的预期，必须逐项注明“旧值→新值→依据”。
