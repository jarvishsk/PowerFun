# 2026 千岛湖半程马拉松（背靠背第二站）训练计划

- 比赛日期：2026-11-22（周日）
- 文档生成：2026-11-15（横店半马 1:48 完赛当日）
- 背景：距横店半马仅 7 天，赛后负荷 697 为近期均值 2.5 倍，身体处于深度疲劳
- 本周核心原则：**恢复优先于一切，不补跑、不加量、不追配速**

## 一、本周课表（11-15 至 11-22）

| 日期 | 安排 | 说明 |
|---|---|---|
| 11-15 周日 | 赛后恢复：拉伸 15min、补水补碳，**全休** | 今日不再安排任何活动 |
| 11-16 周一 | 全休或步行 30min | 观察腿部酸痛程度与晨脉 |
| 11-17 周二 | 轻松跑 6-8km，Z1（心率 ≤145） | 排酸跑，只看心率不看配速；疲劳明显则再休一天 |
| 11-18 周三 | 轻松跑 8-10km + 4×80m 加速跑 | **质量验收点**：晨脉高于基线 5bpm 以上则改为全休 |
| 11-19 周四 | 小质量课：热身 2km + 4km @ 5:00-5:05 + 放松 2km（总量 ≤10km） | 全场唯一强度刺激，目的只是"唤醒"而非提升；心率异常偏高则中途降回轻松配速 |
| 11-20 周五 | 全休 | 充碳开始，整理装备 |
| 11-21 周六 | 激活：慢跑 12-15min + 3×60m 加速跑 | 可省略；早睡 |
| 11-22 周日 | **千岛湖半程马拉松** | 目标分档见第二节 |

## 二、比赛目标分档（按 11-18/19 验收结果定档）

| 定档条件 | 比赛目标 |
|---|---|
| 周三跑步腿感轻松、周四 4km@5:00-5:05 心率 ≤170 且次日无疲劳残留 | **1:47-1:48**（横店同档，冲击 1:44 不建议） |
| 恢复正常但周四心率 170-175 | **1:49-1:51**（基准档，推荐按此起跑） |
| 周三/周四仍感疲劳或晨脉偏高 | **1:52-1:55**，当高质量训练课，不为成绩硬顶 |

- 起跑纪律沿用横店方案：前 5km 只慢不快，5km 检查点后再评估。
- 基准档（1:50）配速 5:10/km，检查点：5km 25:50 / 10km 51:40 / 15km 1:17:30。
- 心率参考：本场以体感为主，腕式心率若再出现 180+ 跳变直接忽略该读数。
- 补给：沿用横店已验证方案；千岛湖赛道路面与桥坡情况赛前再确认。

## 三、红线

1. 本周总跑量不超过 30km（横店赛前一周约 40km+）。
2. 周四是唯一强度课，不提前、不加组；任何一天晨脉高 5bpm 以上当天改休。
3. 不因"状态不错"临时增加训练内容——本周的任务是让 11-15 的 697 负荷出清。
